# 红色警戒 - 网页版

一个基于HTML5 Canvas的网页版红色警戒游戏。

## 如何运行

1. 直接在浏览器中打开 `index.html` 文件
2. 或者使用本地服务器：
   ```bash
   # 使用Python
   python -m http.server 8000
   
   # 使用Node.js
   npx http-server
   
   # 使用PHP
   php -S localhost:8000
   ```
3. 然后在浏览器中访问 `http://localhost:8000`

## 游戏操作

### 基本控制
- **左键点击**：选择单位或建筑
- **左键拖拽**：框选多个单位
- **右键点击**：移动单位或攻击目标
- **滚轮**：缩放视角
- **空格键**：暂停游戏
- **+/- 键**：调整游戏速度
- **S 键**：保存游戏
- **L 键**：加载游戏
- **Delete 键**：删除选中的单位

### 资源管理
- 采矿车会自动采集黄色矿石
- 矿石会自动运回矿场转化为资金
- 资金用于建造建筑和生产单位

### 建筑系统
- **建造厂**：建造其他建筑
- **发电厂**：提供电力
- **矿场**：接收采矿车采集的资源
- **兵营**：生产步兵单位
- **战车工厂**：生产车辆单位
- **机枪碉堡**：防御建筑
- **火箭碉堡**：强力防御建筑

### 单位类型
- **采矿车**：采集资源
- **主战坦克**：主力作战单位
- **轻型坦克**：快速但脆弱
- **步兵**：基础作战单位
- **火箭兵**：远程攻击单位

### 胜利条件
- 摧毁所有敌方建筑和单位即可获胜
- 如果你的所有建筑和单位都被摧毁则失败
