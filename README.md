# 红色警戒 - 网页版

一个基于HTML5 Canvas的网页版红色警戒即时战略游戏。

## 如何运行

1. 直接在浏览器中打开 `index.html` 文件
2. 或者使用本地服务器：
   ```bash
   # 使用Python
   python -m http.server 8000

   # 使用Node.js
   npx http-server

   # 使用PHP
   php -S localhost:8000
   ```
3. 然后在浏览器中访问 `http://localhost:8000`

## 游戏操作

### 基本控制
- **左键点击**：选择单位或建筑
- **左键拖拽**：框选多个单位
- **Shift+左键**：加选/减选单位
- **右键点击**：移动单位或攻击目标
- **Ctrl+滚轮**：缩放视角
- **滚轮/Shift+滚轮**：滚动地图
- **空格键**：暂停/继续游戏
- **Delete 键**：删除选中的单位
- **F5**：保存游戏
- **F9**：加载游戏

### 单位命令
- **S 键**：停止当前命令
- **A 键**：攻击移动（移动并自动攻击沿途敌人）
- **G 键**：守卫当前位置
- **Ctrl+A**：全选己方单位
- **Ctrl+数字 1-9**：建立编队
- **数字 1-9**：召回编队（双击跳转视角）
- **Home 键**：回到主基地视角

### 资源管理
- 采矿车会自动采集黄色矿石
- 矿石会自动运回矿场转化为资金
- 资金用于建造建筑和生产单位

### 建筑系统
- **建造厂**：基地核心，提供50电力
- **发电厂**：提供200电力
- **矿厂**：精炼矿石，附赠采矿车
- **兵营**：训练步兵单位
- **战车工厂**：制造车辆单位
- **雷达站**：解锁小地图视图
- **科技中心**：解锁高级科技单位
- **维修站**：附近车辆自动维修

### 防御建筑
- **城墙**：廉价障碍物
- **碉堡**：快速射击步兵防御
- **重炮塔**：反装甲重炮
- **防空炮**：快速射击火力
- **特斯拉线圈**：强力电磁攻击（需科技中心）

### 单位类型
- **步兵**：基础步兵
- **火箭兵**：反装甲步兵
- **工程师**：修建筑/占领敌方建筑
- **坦克**：主战坦克
- **重型坦克**：重型装甲单位（需科技中心）
- **自行火炮**：超远程范围炮击
- **运兵车**：快速突击车
- **多管火箭**：连射火箭车（需科技中心）
- **采矿车**：自动采集矿石

### 胜利条件
- 摧毁敌方建造厂即获胜
- 如果你的建造厂被摧毁则失败

## 游戏特色

- 完整的RTS游戏体验
- 三种难度（简单/普通/困难）AI对手
- 资源采集和管理
- 电力系统
- 多种建筑和单位类型
- 小地图显示
- 编队系统
- 游戏存档/读档功能
- 可调节游戏速度（1x/2x/4x）
- 视角缩放

## 技术实现

- HTML5 Canvas 渲染
- 纯JavaScript实现
- 面向对象编程
- A*寻路算法
- 游戏循环和状态管理
- AI行为系统
- Web Audio API 音效
